FAQ'S:

What is tree?
Ans: Tree is a nonlinear data structure used for hierarchical data management.

What is binary tree?
Ans:A binary tree is an empty tree or it is finite set of nodes with root and two disjoint binary trees called left subtree and right subtree.

What are the types of Binary tree.
Ans:Complete binary tree,Full binary tree,binary search tree, Skewed binary tree ,threaded binary tree etc.

What are tree traversal techniques. 
Ans:1)Recursive 2)Non recursive

What are recursive tree traversal techniques. 
Ans: 1)Inorder 2)Preorder 3)Postorder

What are AVL trees>
Ans: AVL trees are height balanced trees.

What are the basic operations that can be performed with tree? 
Ans: 1)Create 2)Search3)Traversal etc

Explain the term degree and height of tree.
Ans:Degree of tree : The number of subtrees of a node is called as its degree.
Height or depth of tree: It is the maximum level of any node in the tree.
